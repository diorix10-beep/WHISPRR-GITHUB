# 🛡️ 11 — Iconography System

Version 1.0

This specification governs icon usage and visual symbols across CHIMERA.

---

## 1. Icon Library Standard
- **Lucide React (`lucide-react`)**: Official icon set for CHIMERA.
- **Consistent Stroke Width**: `strokeWidth={2}` by default (`strokeWidth={2.5}` for primary action icons like `Plus`).

## 2. Iconic Symbol Mapping
| Concept | Icon | Color Accent |
|---|---|---|
| Roleplay Mode | `MessageSquare` | Red (`text-red-500`) |
| Storytelling Mode | `BookOpen` / `PenTool` | Purple (`text-purple-500`) |
| SHARDS Currency | `ShardCrystalImage` / `Gem` | Cyan (`text-cyan-300`) |
| Character Identity | `Users` / `Bot` | Violet (`text-violet-400`) |
| Audio & Voice | `Volume2` / `Sparkles` | Amber (`text-amber-300`) |
| Pioneer Creator 2026 | `🔮` / `Crown` | Purple Pulse (`animate-pulse`) |
