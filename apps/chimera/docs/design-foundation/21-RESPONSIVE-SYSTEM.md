# 📱 21 — Responsive System

Version 1.0

This specification governs responsive breakpoints and mobile-first layout rules.

---

## 1. Rule 1 — Mobile & Desktop First (Mandatory)
- Both desktop and mobile platforms are first-class citizens with 100% feature parity.
- Never hide primary functionality on mobile without a responsive equivalent.

## 2. Breakpoint Tokens
- `sm`: 640px
- `md`: 768px
- `lg`: 1024px (Desktop navbar switch)
- `xl`: 1280px
- `2xl`: 1536px
