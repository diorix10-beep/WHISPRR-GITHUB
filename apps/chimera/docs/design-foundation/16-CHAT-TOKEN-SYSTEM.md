# 💬 16 — Chat Token System

Version 1.0

This specification governs single & multi-character roleplay chat rooms across CHIMERA.

---

## 1. Multi-Character Group Rooms
- **Scene Participants**: Support multiple AI characters in a single chat room.
- **Active Speaker Switching**: `Speak Next` trigger button to manually or automatically determine turn speaker.
- **In-Chat Audio Playback**: Speaker button on every message bubble that strips action text (`*smiles*`) before reading spoken dialogue.
- **Transcript Exporter**: Export chat sessions into formatted HTML web novel documents.
