# 📖 17 — Story Token System

Version 1.0

This specification governs the Novel Reader, Writer's Desk, and AI Co-Writer mode.

---

## 1. Novel Reader Standards
- **AO3 / Wattpad Style**: Distraction-free reading view with custom reading themes (`Dark`, `Sepia`, `Light`), font families (`Serif`, `Sans`, `Mono`), and font size controls.
- **"Step Inside Scene 🌀"**: Transition directly from reading a novel chapter into live interactive roleplay with the characters.
- **Passage Annotations**: Paragraph-level inline commenting.
