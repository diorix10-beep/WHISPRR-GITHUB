# ♿ 22 — Accessibility Constitution

Version 1.0

This specification governs accessibility standards across CHIMERA.

---

## 1. Rule 20 — Accessibility is Mandatory
- **Keyboard Navigation**: All interactive controls must be reachable via `Tab` / `Shift+Tab` and triggerable via `Enter` / `Space`.
- **Visible Focus Rings**: `focus-visible:ring-2 focus-visible:ring-purple-500` on all buttons and inputs.
- **Touch Target Size**: Minimum 44x44px target area on touch devices.
- **Screen Reader Support**: Descriptive `aria-label` tags on all icon-only buttons.
- **Color Contrast**: Minimum 4.5:1 text contrast ratio against container background.
