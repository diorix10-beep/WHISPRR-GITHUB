# 🎭 15 — Character Token System

Version 1.0

This specification defines AI Character schema, system prompt compilation, and voice profiles.

---

## 1. Character Architecture
- **Fields**: Name, Short Description, Long Biography, Personality, First Greeting, Scenario, Example Dialogues, Category, Content Rating (SFW/NSFW).
- **Universal Image Upload (Rule 52)**: Drag & drop, crop, preview, no raw URLs required.
- **Voice Signature Studio**: Web Speech API & ElevenLabs voice presets with audition previews.
- **Character Importer**: Supports Tavern/V2 PNG character card metadata extraction.
