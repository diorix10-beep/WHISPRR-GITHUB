# 🌓 09 — Theme Token System

Version 1.0

This specification defines theme modes across CHIMERA.

---

## 1. Supported Themes
- **Night Dark (`dark`)**: Primary theme (`#09090B` background, glassmorphism overlays, glowing cyan SHARDS).
- **Paper Sepia (`sepia`)**: Warm reading theme (`#FBF0D9` background, `#2C221E` serif text, parchment feel).
- **Crisp Light (`light`)**: High-contrast daylight theme (`#FFFFFF` background, `#18181B` text).

## 2. Glassmorphism Standard
- `backdrop-blur-md bg-warm-900/80 border border-warm-800/80 shadow-2xl`
- All sticky headers, floating action bars, and modal backdrops must apply backdrop blur.
