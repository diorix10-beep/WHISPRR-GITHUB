# 🎨 CHIMERA Design Constitution

Version 1.0

This document defines the permanent design principles that govern the visual identity of CHIMERA and WHISPRR.

---

## SECTION I — VISUAL HARMONY & TOKENS

### Rule 1 — Token-First Architecture
- Every visual value (color, font size, spacing, border radius, shadow, motion) MUST consume shared design tokens.
- Never hardcode raw hex colors (`#1a202c`) or arbitrary pixel values in component styling.

### Rule 2 — Whitespace is a Feature
- Spacing creates clarity. Breathing room creates elegance.
- Never attempt to fill every available pixel. Preserve intentional whitespace.

### Rule 3 — Creative Mode Visual Identity Isolation
- **Roleplay Mode**: Crimson Red primary accent (`--rp-accent-bg`). Warm, dark, expressive atmosphere.
- **Storytelling Mode**: Royal Violet primary accent (`--story-accent-bg`). Distraction-free typography & prose workspace.
- Never mix creative mode identities.

---

## SECTION II — UNIVERSAL COMPONENTS & ASSETS

### Rule 52 — Universal Image Upload System
- Every image upload in the ecosystem must use the single `UniversalImagePicker` component.
- Supports Click to Upload, Drag & Drop, Mobile Photo Picker, Camera, Crop, Zoom, Reposition, Replace, and Remove.
- Raw image URLs are managed internally; end-users never see or manually copy raw image URLs.

### Rule 54 — 3D Asset Quality Standard
- All 3D assets (SHARDS, trophies, badges) must maintain a premium sapphire crystalline aesthetic with realistic refraction, sharp facets, and subtle luminescence.
- Never use cartoonish, plastic, or toy-like 3D assets.
